# Research Gap & Novelty Review

## Purpose
This document prevents the project from making an unsupported novelty claim. The final contribution must be established through a systematic literature and product review.

## Current hypothesis
The potentially differentiating contribution is not generic HR prediction, generic AutoML, generic agentic AI, or generic workforce decision support. Those areas already contain substantial prior work.

The working research direction is a domain-specific autonomous analytics pipeline that:

1. accepts heterogeneous HR datasets;
2. semantically interprets inconsistent source schemas;
3. determines which HR analytical objectives are feasible from available variables and labels;
4. creates an analytical execution plan;
5. routes data processing through scalable Big Data tooling;
6. selects and evaluates suitable analytical/ML workflows;
7. explains model findings;
8. produces traceable decision-support recommendations.

## Known overlap to investigate
Initial searches have already identified prior work in:
- autonomous/general data-science agents;
- agentic HR/workforce analytics;
- HR predictive analytics and attrition modelling;
- explainable AI for HR;
- AutoML for tabular data.

These areas cannot be presented as novel by themselves.

## Required literature/product review
Before finalizing the research contribution, create a comparison matrix covering at minimum:
- autonomous data-science agents;
- agentic HR systems;
- HR workforce analytics platforms;
- AutoML systems;
- semantic schema matching/data discovery systems;
- Big Data analytics agents;
- decision-support systems in HR.

For each system/paper record:
- citation/product;
- year;
- input types;
- schema understanding;
- objective discovery;
- agent planning;
- Big Data processing;
- ML/model selection;
- explainability;
- recommendation/decision support;
- human-in-the-loop controls;
- limitations;
- overlap with this project.

## Novelty rule
Do not write “first”, “never built”, “no one has done this”, or equivalent claims unless supported by a defensible literature/product review.

## Candidate contribution
A candidate contribution may be a reproducible architecture or method for autonomous HR analytical workflow discovery under heterogeneous schemas and scalable execution, but this remains a hypothesis until validated.

## Status
Research gap is OPEN. Implementation must not depend on an unverified novelty claim.
